# aekanshgoel.github.io

Personal writing site for [Aekansh Goel](https://github.com/aekanshgoel).

Live site: https://aekanshgoel.github.io

This is a Jekyll site. Add articles as Markdown files in `_posts`.

## GitHub Pages

1. Make this repository **public** if it is private (needed for free GitHub Pages).
2. Settings → Pages → Source: **GitHub Actions**
3. The workflow in `.github/workflows/pages.yml` publishes on push to `main`
